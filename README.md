# Linked List Management System in C++

## Project Overview

The **Linked List Management System** is a menu-driven C++ application that demonstrates the implementation and operations of two fundamental data structures: Singly Linked Lists and Doubly Linked Lists.

The project allows users to perform various linked list operations, understand how nodes are connected, and compare the functionality of both types of linked lists.

## Technologies Used

- **Programming Language:** C++
- **IDE:** Visual Studio Code
- **Compiler:** GCC (G++)
- **Concepts:** Data Structures, Pointers, Dynamic Memory Allocation, Classes and Functions

## Features

### 1. Singly Linked List

- Insert a node at the beginning.
- Insert a node at the end.
- Insert a node at a specific position.
- Insert a node before or after a given value.
- Delete the first node.
- Delete the last node.
- Delete a node at a specific position.
- Delete a node by value.
- Search for an element.
- Update an element.
- Display the linked list.
- Count the total number of nodes.
- Find the maximum and minimum elements.
- Find the middle element.
- Reverse the linked list.
- Sort the linked list.
- Remove duplicate elements.

### 2. Doubly Linked List

- Insert a node at the beginning.
- Insert a node at the end.
- Insert a node at a specific position.
- Insert a node before or after a given value.
- Delete the first node.
- Delete the last node.
- Delete a node at a specific position.
- Delete a node by value.
- Search for an element.
- Update an element.
- Display the linked list in forward order.
- Display the linked list in backward order.
- Count the total number of nodes.
- Find the maximum and minimum elements.
- Find the middle element.
- Reverse the linked list.
- Sort the linked list.
- Remove duplicate elements.

### 3. Comparison

The project also provides an option to explore and compare the operations of Singly Linked Lists and Doubly Linked Lists.

## Edge Cases Handled

The program considers important edge cases, including:

- Operations on an empty linked list.
- Insertion and deletion involving a single node.
- Invalid positions.
- Searching for elements that do not exist.
- Handling duplicate elements.
- Lists containing positive, negative, and zero values.
